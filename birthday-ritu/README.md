# Birthday Surprise Website for Ritu

## Preview locally
Open `index.html` in a modern browser. The music button starts a gentle original chime sequence after a click.

## Publish free with GitHub Pages
1. Sign in to https://github.com/ and create a new **public** repository, e.g. `birthday-ritu`.
2. Upload both `index.html` and `ritu.jpg` to the repository root (the first/main page should be named exactly `index.html`).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish publishing. The public URL will usually be:
   `https://YOUR-USERNAME.github.io/birthday-ritu/`
   Replace `YOUR-USERNAME` with your GitHub username and `birthday-ritu` with the repository name. Use the actual URL shown under Settings → Pages once it is ready.

## Notes
- No backend, paid service, API key, or external image/music file is required.
- The soft melody is generated by the browser with Web Audio and begins only after the visitor taps Music (browser autoplay rules).
- Anyone with the public URL can view the page. The personal message and recipient name are public, so share only if you're comfortable with that.
